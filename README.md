# HADA Content Studio — Local Sample

This local demonstration uses one fictional character, Cute Elf Girl, to show how
the shared identity stays stable across a full-body reference and a chibi appearance.
A reusable scholar outfit is modeled separately as an item and linked to the character.

The Japanese capability infographic walks through mini-projects, sourced knowledge,
layered prompt provenance, protected image masters, Python watermark/export profiles,
metadata checks, and post-publication records. The raw generated references and exact
prompt sidecars remain local. Exported images are still marked for human review; this
Sample does not upload or claim to publish them.

Read the project-root `WHY.md` before significant work. When the owner states or adopts
a durable reason, run `python tools/record_why.py --root PROJECT_ROOT` to append it
without replacing earlier entries.

Run python tools/validate.py and python tools/catalog.py from this directory.
See docs/ASSET_LIFECYCLE.md before using any image outside the local project.

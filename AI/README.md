# AI Work Area

Use this area only for explicitly temporary agent task material. Durable project
knowledge, assets, decisions, and production records belong in their declared locations.

Conversation logging is optional and off by default. This project does not passively
collect or automatically retrieve chats. Imported conversation files under `AI/Logs/`
are user-owned provenance, separate from canonical decisions and the durable rationale
in `WHY.md`; they are not template content or disposable work.

Never interpret an AI Reset as permission to clear the whole directory. There is no
whole-directory reset command or automatic cleanup policy. Reset only specifically
identified disposable task scratch. Preserve durable knowledge, assets, decisions,
reports, user-owned conversation archives, and unknown files. One-time visual-reference
analysis uses its separately declared transient area and is discarded only when the
specific session is explicitly completed.
